# OZ v0.1.0 — validation notes

Проверено в рабочей среде:

- JSON ресурсов парсится без ошибок.
- Все прямые `function oz:...` ссылки указывают на существующие функции.
- Старых прямых вызовов удалённого `zone/sample` / `zone/candidate` pipeline не осталось.
- Старых ссылок на generated border tree не осталось.
- 392 generated border functions удалены.
- Встроенный datapack уменьшен с 538 до 132 mcfunction-файлов.
- Java square-spiral для индексов 1..256 полностью совпадает со старым `zone/candidate/set.mcfunction`.
- `Text.Serializer.toJson(...)` используется для Yarn 1.20.1 вместо более нового `Text.Serialization`.
- `World#getTopY(Heightmap.Type, x, z)` используется только для текущей позиции игрока, то есть не служит механизмом удалённого поиска зон.
- `javac` не обнаружил синтаксических ошибок до стадии разрешения отсутствующих внешних Minecraft/Fabric классов.

Не проверено здесь из-за отсутствия Gradle/Fabric/Minecraft зависимостей и сетевого доступа из build-контейнера:

- полноценная Gradle/Loom компиляция;
- remap JAR;
- запуск dedicated server 1.20.1;
- совместимость на конкретной сборке Origins пользователя;
- профилирование MSPT на реальном мире/сервере.

Первый реальный тест нужно делать на копии мира и смотреть `latest.log`; если какая-либо Yarn/Fabric сигнатура отличается в конкретной сборке, это будет точечная правка, а не возврат к старой архитектуре.
